C545D 新デコーダ版 / 簡単起動

1. このZIPを「すべて展開」してください。
2. C545D_Start.vbs をダブルクリックしてください。
3. 録画アプリが開いたら「録画開始」を押してください。

H.264デコーダは avdec_h264 を最優先にします。
使えない場合は従来の openh264dec 等へ自動切替します。
実際の選択結果は録画ログの「Decoder:」で確認できます。

x264 medium / Quantizer 24 / 2560x720 / 15fps / AAC / 2画面合成は変更していません。
CPUの経時上昇が止まるかはWindows 10実機では未検証です。
この版は起動だけを簡素化しています。
