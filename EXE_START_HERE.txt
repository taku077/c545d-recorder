C545D録画アプリ — Windows 10 x64 EXE版（移行第2段階／試験版）

■ 今回の変更
操作画面・設定操作・録画開始・停止・トレイ制御を C# WinForms に移行しました。
録画する映像・音声の処理は、前段階と同じ PowerShell + GStreamer を維持しています。
PowerShellスクリプトの録画バックエンドは同梱され、アプリ内部から実行されます。
C#単独で録画・エンコードするソフトにはまだなっていません。

■ インストール
1. GitHub Releasesの Assets にある C545D_Recorder_EXE_Win10_x64.zip を取得します。
   ActionsのArtifacts画面は使わなくて構いません。
2. ZIPを右クリックして「すべて展開」し、旧版とは別フォルダーに置きます。
3. 現在録画している場合、旧版で録画停止し、MP4の確定を確認してください。
4. C545D_Recorder.exe をダブルクリックすると、新しいC#操作画面が開きます。
5. 従来の設定とDPAPIパスワードは、同じWindowsユーザーならそのまま使用できます。
6. 「録画開始」で開始し、「録画停止」でMP4確定まで待ちます。

■ 録画仕様（変更なし）
- 望遠 stream6 と広角 stream1 を横並びで1つのMP4に記録
- x264 medium、Quantizer 24、2560×720、15fps、avdec_h264優先
- AAC音声1系統、1時間MP4分割、NTP/tcp-timestampの同期
- 最終MP4を安全に閉じるため Ctrl+C → GStreamer EOS を維持
- 撮影映像プレビュー無し、CPU/WorkingSet/Private表示と30秒ごとのCSV
- 保存パスワードは従来どおり Windowsユーザーに紐づく DPAPI

■ 注意
- ZIP内のファイルは全て同じフォルダーに置いてください。EXE単独では動作しません。
- GStreamerのインストールは従来どおり必要です。
- 旧版と新しいEXE版を並行起動しないでください。
- 旧版フォルダーは必ず残してください。
- 現時点は実機での「停止 → MP4確定 → 再開」確認前の試験版です。
- EXE化はメモリ増加問題の修正ではありません。24時間365日の安定性は未検証です。
- 画面にある「緊急停止」は最終手段です。通常停止でMP4確定を待ってください。

■ 旧版へ戻す
以前の正常動作版のZIP・フォルダーは上書きしないで保持してください。
C545D_Start.vbs は従来PowerShell GUIを開く入口として同梱してあります。


■ 第2段階のコンソール表示・映像時刻修正候補（2026-11-17）
- 録画ワーカー用PowerShellコンソールを従来どおり非表示起動に戻しました。
  Ctrl+Cによる正常終了・MP4確定に必要な専用コンソールは維持します。
- RTSP H.264入力をアクセスユニット単位に整列し、パケット欠落後の
  キーフレーム待機を有効にする方向で修正しています。
- GStreamer付属 h264timestamper が使用可能で合成映像テストに成功した
  場合に限り、エンコード後のDTS補正を有効化します。
  使用不可またはテスト失敗時は従来の経路へ戻ります。
- 画面が非表示になるだけでGStreamerの警告自体を消す変更ではありません。
  警告の有無は録画ログで確認できます。
- 実カメラによる映像・DTS修正の効果は未確認です。
- 補正が問題を起こした場合、録画開始前に
  C545D_DTS_GUARD=off を設定することで従来のDTS経路に戻せます。
  実行中の録画には適用されません。


■ RC11: 意図しない中断からの復帰（2026-11-17）
- 正式な「録画停止」の記録がある場合だけ、録画セッションを終了します。
- 不意にCtrl+Cを受けたりgst-launchが終了コード0で終了した場合は
  「正常停止」と誤認せず、既存の再接続待機（初回20秒・最大60秒）

- 中断した間の映像は自動復元されません。最終MP4を強制終了せず

  UNEXPECTED_CTRL_C / UNEXPECTED_GSTREAMER_EXIT を記録します。
- C#操作画面も停止ボタンなしのワーカー終了を赤字で警告します。
- x264 medium/Q24、AAC、2画面NTP同期、1時間分割を変更していません。
- メモリリークと libav no frame!/DTS 警告の実機改善は未確認です。
- 現在の録画を停止せずに差し替えないでください。


■ RC13 — libav no frame / MP4 DTS 補正候補（試験版）
今回の修正対象はH.264入力デコードと、AAC音声の時刻連続性です。
1) H.264 RTPデペイロード後のパーサーでSPS/PPSの毎IDR再挿入を停止し、
   access unit単位のbyte-streamへ整列します。
   起動前の合成RTP映像試験が成功した場合のみ有効になります。
   C545D_H264_INPUT=legacy で以前の方式に戻せます。
2) AAC側はaudiorate（40ms許容、skip-to-first=true）を追加し、
   MP4に渡す音声タイムスタンプを安定させます。
   起動前の合成AAC→MP4試験が成功した場合のみ有効になります。
   C545D_AUDIO_TS=legacy で元に戻せます。
3) RC10導入済みのh264timestamper（映像DTS補正）を保持します。
   ログの 'MP4 DTS guard:' で有効かどうか確認できます。

起動時ログの 'H264 RTP input guard:' と 'AAC timestamp guard:' に
各機能の有効／フォールバック状態を記録します。
両方式ともGStreamer付属機能だけを使用し、新規ソフト導入は不要です。

重要：合成テストでは実際のC545Dストリームに依存するno frame/DTS
警告の解消までは検証できません。警告は抑制せずログに残します。
音声補正は、時刻が大きくずれた部分でサンプルの補間・削除を
行う場合があります。画質・x264 quantizer・映像同期を変更しません。
録画中の旧版を停止せずに新しいEXEへ切り替えないでください。
