C545D録画アプリ — Windows 10 x64 EXE版（移行第1段階）

■ 使い方
1. ダウンロードした ZIP を右クリックし「すべて展開」します。
2. 展開したフォルダー内の C545D_Recorder.exe をダブルクリックします。
3. 従来と同じ録画操作画面が開きます。
4. 「録画開始」「録画停止」は従来どおり画面上で操作してください。

■ この版について
- EXE自体はC#／.NET Framework 4.8で作成された起動プログラムです。
- 現段階では操作画面と録画処理に既存PowerShellファイルを使用します。
- この版を「録画アプリ全体のC#移植完了」とは扱いません。
- 次の段階で操作画面をC# WinFormsへ移行します。
- x264 medium / Quantizer 24 / 2560×720 / 15fps / avdec_h264優先
  / デュアルRTSP / AAC音声 / 1時間MP4分割等の録画設定は変更していません。
- 録画停止の処理も既存の安全なCtrl+C→EOS処理を変更していません。

■ 注意
- EXEだけ取り出して起動しないでください。同梱の9ファイルが必要です。
- GStreamerは従来どおり別途PCにインストールされている必要があります。
- カメラの認証情報と保存先設定は既存のユーザーローカル領域に保存され、
  ZIPには含みません。普段のWindowsユーザーで実行してください。
- 録画中の旧アプリを止めずに、さらに新しいアプリを起動しないでください。
  同一カメラへのRTSP多重接続で正常に取り込めなくなるおそれがあります。
- 実機での録画・停止・再起動・長時間動作は、今後の検証項目です。
- GitHub Actionsのビルド・簡易起動試験だけでは実機動作は保証できません。

■ トラブル時
- 旧版の C545D_Start.vbs もそのまま同梱しています。
- EXE版が起動しない場合、EXE配布ZIPを上書きせず、元の正常動作版を使用してください。
- タスクマネージャーからの強制終了は最終MP4を破損させる可能性があるため避けてください。
